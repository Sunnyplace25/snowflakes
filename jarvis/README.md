# Snow flakes JARVIS

Snow flakes プロジェクト専属のAI運営アシスタント。
公式サイトの更新・SNS投稿文の作成・スケジュール管理・履歴記録を一元管理する。

作者：山吹ことり
対象サイト：https://sunnyplace25.github.io/snowflakes/

---

## 基本方針

- 外部への影響がある操作（サイト公開・SNS投稿・git push）は **必ず人間の承認後** に実行する
- 自動commit・自動pushは初期設定で **無効**
- APIキーやアクセストークンは `.env` のみで管理し、ソースコードへ直接書かない
- ログにはAPIキー・プロンプト全文・個人情報を記録しない
- `git add` は対象ファイルを **個別指定** する（`git add .` は使用禁止）
- 作業は `jarvis-development` ブランチで行い、`main` へは承認後のみマージする

---

## フォルダ構成

```
jarvis/
├── .env.example        キー名のみのテンプレ（値は空）
├── .env                本番用キー（Git管理外・手動で作成）
├── README.md           このファイル
├── package.json        npmパッケージ管理
├── config/
│   └── settings.json   サイト設定・SNS設定・予算上限・自動投稿許可
├── logs/
│   └── *.log           操作履歴（Git管理外）
├── drafts/
│   ├── pending/        承認前の一時下書き（Git管理外）
│   ├── approved/       承認済みの内容（Git管理）
│   └── published/      公開済み記録（Git管理）
└── tools/
    └── generate_draft.js  下書き生成ツール
```

---

## セットアップ手順

1. `.env.example` を複製して `.env` にリネームする
2. `.env` の各キーに値を入力する（値は絶対にGitへコミットしない）
3. `jarvis/` フォルダで `npm install` を実行する（初回のみ）
4. `node tools/generate_draft.js` で下書き生成ツールを起動する

## 注意事項

- `drafts/pending/` 内のファイルはGit管理外。承認前に外部へ共有しない。
- 画像・音声ファイルはdrafts内へ複製せず、元ファイルの相対パスのみを記録する。
- 予算上限に近づいた場合は警告を表示し、上限超過時は処理を停止する。
- 失敗した処理は自動で再試行せず、原因と対応案を表示して停止する。
