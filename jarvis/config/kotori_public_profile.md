# 山吹ことり 公開プロフィール

出版事業部の全AI社員が参照する、山吹ことりの公開情報です。
記事・コンテンツ作成時は必ずこのファイルを参照し、記載のない情報を推測・補完しないでください。

---

## 基本情報

- **名前**：山吹ことり（やまぶき ことり）
- **活動拠点**：非公開
- **職業・肩書き**：創作活動（小説・音楽・イラスト・Web）、音声関連の仕事

## 創作活動

### 小説
- 自作の小説世界（複数の作品が同一世界に存在する）を執筆している
- 代表作品世界：**Snow flakes**（スノーフレークス）
- 長編・シリーズを書いており、登場人物の設定・時系列・作品間のつながり・伏線・過去設定が非常に膨大
- AIは**小説本文を書かせているのではなく**、膨大な設定を整理・確認するために活用している
  - 人物設定、時系列管理、作品間のつながり、伏線の追跡、過去設定の参照などが主な用途
  - AI = 小説執筆ツール、という表現は**誤り**。使用しないこと

### 音楽
- 楽曲制作を行っており、生成音源（Suno等）を使用している
- 生成した音源をそのまま使うのではなく、ステム、MIX、EQ、ドラム、ベース、ボーカル、LUFS、True Peak、配信用音源まで確認・調整して仕上げる
- 音声関連の仕事を経験しており、音のクオリティにこだわりがある
- 小説の登場人物のために実際の楽曲を制作することがある（Snow flakesなど）

### イラスト・ビジュアル
- 小説世界に合わせたビジュアルも制作している
- ジャケット、キャラクタービジュアルなど

### Web
- 作品世界に関連したWebコンテンツも制作している

## JARVIS（自作AI支援システム）

- SNSで「自分専用のJARVISを作る」という投稿を見て、「自分も作ってみたい」と思ったことがきっかけ
- 最初から大規模なシステムを作ろうとしたわけではなく、作っていくうちに現在の仕組みへ発展した
- 現在はAI社員6名が稼働している（Scout/ヒカゲ、Analyst/ヒノデ、Planner/アサヒ、Writer/ソラ、Editor/キイロ、Growth/アオ）
- note記事の市場調査・企画・執筆・編集を半自動化している

- 小説・音楽・イラスト・Web・物販など、複数の活動が「頭の中にあるものを実際に存在させたい」という一つの根からつながっている

## 公開禁止情報（記事・コンテンツに絶対に記載しないこと）

- 具体的な職業名・職種（例：保育士、看護師、教師など）
- 本名・住所・年齢・家族構成などの個人情報
- 本人が公表していない実績・数字・体験・感情
- 「〜したいと思っています」「〜を楽しんでいます」など、本人の内面を推測した表現
- AIが小説本文を書いている、という誤解を招く表現

## 執筆時の注意事項

1. このプロフィールに記載されていない情報は、推測・補完しない

3. 「AI小説家」「AIで小説を書いている」のような誤解を招く表現を使わない
4. 実績・数字・体験・感情は、本人が提供した情報のみ使用する
