STATUS

5つのゲージで、ハヤテのコンディションをチェック！
おなか / たいりょく / やるき / きぶん が下がりすぎると、ハヤテの調子が悪くなるよ。

れんしゅう ゲージは、ドラム練習でだけ溜まる特別なゲージ。
LIVEに挑戦する前に、しっかり練習しておこう！

ACTION
🍙
ごはん
おなかを回復するよ。腹が減っては練習できぬ。
💤
休憩
たいりょくを回復するよ。眠いまま放置すると、疲れて眠っちゃうことも。
🥁
ドラム練習
れんしゅうゲージを溜めてLIVEを解放！ 練習中は音楽が流れるよ。5回続けると休憩が必要になる。
💬
話しかける
きぶんがアップ。ハヤテのひとことが聞けるよ。話しかけすぎると疲れちゃうかも。
📄
仕事
LIVEの盛り上がりに影響するよ。ライブ前にしっかり配っておこう。
🚶
おでかけ
気分転換に外へ。メンバーと遭遇したり、外食して腹を満たすことも。きぶんが低いときは時間外でも出られるよ。
LIVE

れんしゅうゲージが一定以上溜まると、LIVEに挑戦できるよ。

ライブ中は画面をタップしてハヤテを応援しよう！
終演後はハヤテから一言もらえるよ。

LIVEをこなすと Drum Lv がアップ！
成功すると SWEETs や図鑑アイテムもゲットできる。

ライブ中は音楽が流れるので、音量に気をつけてね。

SWEETs

LIVEが成功するともらえるお菓子。
ハヤテに食べさせると、全ステータスが回復するよ。

GAME

色のシロップを混ぜて、オリジナルカクテルを作ろう。
完成した一杯には、名前とカクテル言葉がつくよ。
1日5杯まで。

COLLECTION

♡ボタンを押すとCOLLECTIONが開くよ。

📖 語録：ドラム練習でハヤテのメモを収集
🍸 カクテル図鑑：バイトで作ったカクテルを記録
🥁 ドラム図鑑：LIVEをこなしてアイテムをゲット
🍴 食べ歩き図鑑：おでかけ外食でたまに発見

DATA BACKUP

必ずメモしておいてください。
